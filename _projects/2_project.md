# Julia Essentials (Project 2)

This project replicates the content from QuantEcon’s Julia Essentials tutorial.

> See: [QuantEcon Julia Essentials](https://quantecon.org/)

The content includes all the essential building blocks of Julia:
- Common data types
- Strings, arrays, dictionaries, tuples
- Iteration and comprehensions
- Closures and scope
- Broadcasting
- User-defined functions

Please refer to **Project 1** for the complete, simplified version of the tutorial. This page serves as a clone or alternate rendering using Jekyll's layout.

## Example Code Snippet

```julia
x = 2;
y = 1.0;
@show 2x - 3y
@show x + y
```

For full details, see the full tutorial in **Project 1**.
